# Frigate - make87-wrapped Version

This is a make87-wrapped version of Frigate that supports only streaming and recording. It accepts RTSP streams via requester/provider and updates if a new stream is added.

- Supports streaming and recording only
- Accepts RTSP streams via requester/provider
- Updates automatically when a new stream is added
